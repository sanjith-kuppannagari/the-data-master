## 🌟 Executive Overview

**THE DATA MASTER** bridges the gap between passive tutorial consumption and career-ready analytical competence. Built on a unique **Digital Observatory & Swiss Editorial** design system (`#101827`, `#171C26`, `#C6F36B`, `#F5F3EA`, `#75D6D0`, `#FFAA73`), it fuses:
1. **Gamified Momentum (Duolingo-style):** Daily learning streaks, level thresholds (Levels 1–10), idempotent anti-duplicate XP rewards (`Rule #21`), 16+ verifiable achievements, and mission boards.
2. **Interactive Technical Sandboxes (DataCamp-style):** Zero-install, browser-executed SQLite WebAssembly (WASM) and client-side Python 3 (Skulpt) with NumPy and DataFrame analytics preludes, interactive spreadsheet formula calculations, and descriptive/inferential statistical engines.
3. **Real-World Business Acumen & Investigation (Kaggle & Case Study style):** 8 multi-modal challenge categories, 7 executive business simulations evaluated against multi-criteria rubrics, and the forensic **Data Detective Bureau** for diagnosing anomaly patterns and financial leaks.
4. **Verifiable Portfolio & Squad Collaboration:** Project starter blueprints, public shareable portfolios with strict draft privacy, community discussions, and collaborative teams.
5. **Free-First Backend Architecture:** 100% offline-ready by default using namespaced browser storage (`LocalDemoBackendAdapter`), with instant optional cloud synchronisation via Supabase REST/PostgreSQL (`SupabaseBackendAdapter`) without paid dependencies.

## ⚡ Core Technical Engines & Features

### 1. Interactive Technical Engines
- **Browser-Native SQLite (WASM):** Client-side relational query execution via `sql.js` against seeded relational databases (`ecommerce`, `hr_analytics`, `saas_metrics`) with real SQL error diagnostic hints.
- **Client-Side Python 3 Runtime (Skulpt):** Real Python 3 execution in the browser with custom `DataFrame` and `_NumPyLite` preludes (`np.mean`, `np.std`, `np.median`, `df.groupby_agg`).
- **Spreadsheet Formula Calculation Engine:** Custom formula parser evaluating arithmetic (`+`, `-`, `*`, `/`), cell references, ranges (`A1:B10`), and functions (`SUM`, `AVERAGE`, `COUNT`, `COUNTA`, `MIN`, `MAX`, `IF`, `SUMIF`, `COUNTIF`, `VLOOKUP`, `XLOOKUP`) with standard error codes (`#DIV/0!`, `#NAME?`, `#VALUE!`, `#N/A`).
- **Statistics Calculation Engine:** Comprehensive descriptive metrics (mean, median, mode, variance, standard deviation, Tukey outliers, quartiles, IQR) and inferential tests (Pearson correlation $r$, Z-scores, 95% confidence intervals, two-sample t-tests).

### 2. Practice Arena & Smart Revision
- **32 Curated Practice Exercises** across 8 modalities with automated grading and explanations.
- **3-Tier Progressive Hints:** Conceptual orientation (Tier 1), Syntactic structure (Tier 2), and Forensic diagnostic (Tier 3).
- **Mistake Journal & Spaced Revision:** Failed attempts log error categories and timestamps; `generateSmartRevisionPlan()` algorithmically ranks revision priority based on recurrence and retention decay.

### 3. Business Simulations & Forensic Mystery Solving
- **7 Executive Business Simulations:** Investigate margin leakage, churn mitigation, promotional discount stacking, fraud detection, and marketing attribution with multi-criteria rubric scoring.
- **Data Detective Bureau:** Step-by-step forensic investigations where learners analyze anomalous transaction trails, inspect evidence dossiers, and submit verified verdicts.

### 4. Portfolio Builder & Collaborative Teams
- **8 Starter Project Blueprints:** Covering Excel modeling, SQL pipelines, Python EDA, RFM segmentation, BI dashboards, and strategic business cases.
- **Public Shareable Portfolio View:** Dedicated `/portfolio/:userId` URL strictly respecting draft privacy.
- **Collaborative Squads:** Create squads, share 6-character invite codes, delegate tasks, and solve team challenges.

### 5. Analytics, Calendar & Gamification
- **Personal Learning Analytics:** Radar charts, daily study heatmaps, rolling accuracy trendlines, and transparent domain mastery scoring (40% completion + 30% accuracy + 30% challenge proof).
- **Interactive Monthly Calendar:** Monthly grid mapping activities to dates with planned study sessions.
- **In-App Notifications & Missions:** Streak alerts, revision reminders, and daily/weekly mission boards with idempotent claiming.

### 6. Free-First Backend Architecture
- **Local-First Offline Adapter (`LocalDemoBackendAdapter`):** Works immediately with zero external accounts or credentials. Complete user state can be backed up as a JSON file or restored safely.
- **Cloud-Ready Adapter (`SupabaseBackendAdapter`):** Seamless optional connection to Supabase Auth and PostgreSQL without heavy proprietary SDKs (uses native Fetch API).
- **Production PostgreSQL DDL:** Full schema in `supabase/migrations/` defining 11 tables with Row Level Security (RLS) policies.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) v18.0.0 or higher
- [npm](https://www.npmjs.com/) v9.0.0 or higher

### Installation
```bash
# Clone the repository
git clone https://github.com/sanjith-kuppannagari/the-data-master.git
cd the-data-master

# Install dependencies
npm install
```

### Development Server
```bash
# Start local development server with HMR
npm run dev
```
Open your browser at `http://localhost:5173`.

### Running Tests
The project features 8 automated test suites covering all phases and quality requirements:
```bash
# Run all automated verification tests
npm test

# Run the 16-point Quality Audit suite specifically
npm run test:audit
```

### Production Build
```bash
# Compile TypeScript and bundle production assets
npm run build

# Preview production build locally
npm run preview
```

## ☁️ Deployment

### Deploying to Vercel
THE DATA MASTER is pre-configured for zero-configuration deployment on Vercel:
1. Fork or push this repository to GitHub.
2. In the [Vercel Dashboard](https://vercel.com/new), import the repository.
3. Keep default settings:
   - **Framework Preset:** `Vite`
   - **Build Command:** `npm run build`
   - **Output Directory:** `dist`
   - **Install Command:** `npm install`
4. Deploy! All single-page application (SPA) client-side routes are handled via `vercel.json`.

### Environment Variables (Optional)
If connecting to Supabase for cloud sync, configure these variables in Vercel:
```ini
VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
```
*Note: If omitted, THE DATA MASTER automatically operates in 100% free, offline Local Demo mode.*

## 🔒 Security & Accessibility

- **No Dangerous Code Evaluation:** Zero `eval()` or `new Function()` in application code. SQL and Python execute within isolated WASM and interpreter sandboxes.
- **Motion Sensitivity:** Honored via `@media (prefers-reduced-motion: reduce)`.
- **Keyboard Navigation:** High-contrast, unambiguous `:focus-visible` indicators across dark and light themes.
- **Screen Reader Support:** Semantic HTML5 landmarks, ARIA modal attributes (`role="dialog"`, `aria-modal="true"`), and `.sr-only` utility classes.
- **Row Level Security (RLS):** Strict PostgreSQL policies ensure user isolation in cloud deployments.
